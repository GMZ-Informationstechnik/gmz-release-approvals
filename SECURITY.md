# Security Policy

Do not report secrets in a public issue. If sensitive information is posted,
remove it from public view immediately and rotate every affected credential.

This repository accepts only public release metadata. The approval protocol is
fail-closed: malformed, edited, stale, mismatched or incorrectly authored
comments must be rejected by the private release workflow.

Security reports about the protocol should be sent through the private GMZ
security reporting channel rather than a public issue.
